About

Researcher, teacher and engineer, usually at the same time.

I am an Associate Professor at the Faculty of Computer Science and Engineering in Skopje, where I lead research and industry projects, lecture, and mentor students. My research sits where machine learning meets large, messy, real-world data: Earth observation and remote sensing, medical imaging and retrieval, and fairness in search.

Alongside academia I have spent more than fifteen years building production systems. At Permian Labs I single-handedly designed and built the NFT collateral analytics that backed over $60M in loan volume. I ran engineering for a retailer-to-carrier shipping platform in Amsterdam, led the recommendation and search team at Infinite Analytics, and founded two companies of my own.

I like problems that need both halves: a model that is only useful once it is wrapped in a reliable API, a pipeline, and a dashboard someone actually opens.

Projects

Selected work

Research · FCSE · open source

AiTLAS: Artificial Intelligence Toolbox for Earth Observation

A toolbox of state-of-the-art machine learning methods for exploratory and predictive analysis of satellite imagery, with a repository of AI-ready Earth observation datasets. It covers land use and land cover classification, crop type prediction, semantic segmentation and more, and underpins an open benchmark arena for EO image classification.

Python · PyTorch · Django · Docker · github.com/biasvariancelabs/aitlas
Permian Labs · 2022–2025

NFT collateral analytics for MetaStreet

A system that gathers market data from many sources, models the collateral value of NFTs and serves the metrics over REST APIs, plus dashboards for the protocol and the wider NFT lending market. It was used to generate over $60M in loan volume.

Python · Docker · TrinoSQL · DuneSQL
European Commission JRC · 2020–2021

Forest-fire social media model

Led development of a multilingual model that detects forest-fire content in Twitter data, integrated into SMDRM, a larger system for crisis management.

Python · PyTorch · Docker
TU Berlin · 2019

FairSearch

Open-source tools for fair ranking: FA*IR post-processing and DELTR in-processing, shipped as an Elasticsearch plugin and Java and Python libraries. Presented at The Web Conference 2020.

Java · Python · Elasticsearch
Storeshippers · 2019–2024

Retailer–carrier shipping platform

Led the team that designed and ran a platform where retailers enter shipments and carriers are assigned automatically by business rules, with every party notified along the way.

Python · Django · PostgreSQL · AWS · React
FCSE · industry projects

Traffic and biometrics

A camera network that measures average vehicle speed and detects violations, and a multimodal biometric authentication system combining face, fingerprint, retina and voice.

Python · Django · Docker
